学習条件まとめ — 2mm / 5mm / 1cm とそのほか

Sawyer Task0（alphabet soup → basket）。先生向けの一覧。 精度ノイズ実験（proprio Gaussian = stategauss）と、open-loop / closed-loop の意味、 共通の学習・評価設定、そのほかの主要条件を1ページに整理。 更新: 2026-10-09（5mm · 学習init評価 / clean100 追記）。

いちばん重要な結果: clean50 Full FT + state ノイズでは 5mm だけ標準評価で 2%（1/50）。 同じ 5mm ckpt を学習 initで測ると 0%（near 38/50 · grasp 4）。 データ倍の clean100 + 5mm も標準・学習initとも 0% （ただし学習initでは grasp 22/100 まで上がる）。成功率そのものは増えなかった。

1. 用語（open / closed など）

Open-loop デモ品質ゲート

記録した action をそのまま再生。ポリシーは使わない。 export 時 --require-open-loop で「再生しても lift+place できるデモ」だけ残す。 clean50 はここに通ったデモだけ。

Closed-loop 本番評価

ライブ観測 → ポリシー → env.step。成功率表はすべてこれ。 誤差が蓄積しやすいので、train で合っても closed で崩れることがある。

Teacher-force 診断

デモの観測を渡して action を予測（開ループ教師強制）。 「学習自体はできているか」を見る。smoke 図で使用。

Stategauss 精度ノイズ

学習時だけ EEF proprio（xyz / ori）に Gaussian を加算。 デモ本数は同じ clean50。評価時はノイズなし。 「状態が数 mm ずれても頑健か」を見るための摂動。

OSC (delta_osc)学習・評価の本線コントローラ（デルタ OSC · 20 Hz）
IK (ik_set)デモ収集時の把握ポーズ。あとで OSC に焼き直し（retrack）
FullLoRA / VisAct / Full FTLoRA（vision+lang+action） / LoRA（vision+action） / 全パラメータ FT

読み方: ノイズは「デモを汚す」のではなく、学習中の proprio 入力をわずかに揺らす。 評価は常にノイズなし closed-loop。 5mm で初めて成功が出た一方、action 側にもノイズを足すと success は消えて grasp だけ増える。 学習init評価 / clean100（2026-10-07 完了）: データ量を倍にしても success は 0% のまま。 学習分布では接近〜掴みは改善するが place まで届かない → 「ep 数不足」より下流制御/リリース側の線が強い。

5. Open-loop / Closed-loop 診断（smoke）

同じ clean50 デモ ep0 で、teacher-force / open-loop 再生 / closed-loop を比較した診断。 成功率ではなく「どこでデモから外れるか」。詳細図は clean50_smoke。

モデル open-loop 再生 EEF 誤差 closed vs open EEF 誤差 teacher-force action L2 verdict
Full FT（ノイズなし） ≈0 ≈0.120 ≈0.204 OL ok · CL weak
FullLoRA ≈0 ≈0.048 ≈0.125 OL/CL ともに比較的健全
stategauss 5mm ≈0 ≈0.074 ≈0.173 OL ok · CL weak（改善は限定的）
5mm + act 1.5mm ≈0 ≈0.051 ≈0.259 OL ok · CL weak · TF は悪化
デモ再生（open-loop）はどの条件でもほぼ誤差ゼロ → データ自体は健全。 Full FT 系は closed-loop で接近後〜掴み付近から外れる、というのが共通の失敗モード。
