データの作り方（何 ep を学習したか）

ポイント: 「学習に使った ep 数」= 下表の train_ep（LeRobot repo の総エピソード数）。 DAgger 条件は scripted ベースに expert takeover デモを合流（多くは expert 成功エピソードを繰り返しマージ）。

A. Scripted ベース（osc_v8）の作り方

  1. Sawyer · Task0 · scripted 軌道をシミュで実行（grasp=ik_set · path_step≈8mm · compact · home_w30）
  2. 接近に approach_noise ≈ 1.5cm × 3 copies（+ clean）を混ぜて多様性を確保
  3. ライブ IK デモを OSC（delta_osc）に retrack して学習用 action に揃える
  4. --require-open-loop: 記録 action の再生で lift+place できるデモだけ残す
  5. 結果: libero_sawyer_scripted_obj0_osc_v8 = 871 ep

B. DAgger の作り方

  1. student（前段ポリシー）を closed-loop で走らせる
  2. 接近失敗・掴み失敗などのトリガで OSC expert が takeover（pose を引き継ぐ）
  3. expert 成功エピソードのみ採用（--require-expert-success）
  4. merge_lerobot_repos.py で scripted（または前 round）と合流。expert 側は extra-repeat（多くは ×10） で増幅
  5. 合流データで再学習（steps=10000 · bs=4）→ LoRA merge → 本評価
